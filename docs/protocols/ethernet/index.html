车载以太网学习

Automotive Ethernet — 从物理层到 TCP/IP 协议栈

车载以太网基础概念

车载以太网是传统以太网技术在汽车领域的适配与演进，通过单对非屏蔽双绞线实现轻量化布线，满足汽车 EMC、延迟和可靠性的严格要求。

核心概念详解

🔌 车载以太网概述

传统以太网使用四对双绞线，车载以太网通过单对非屏蔽双绞线（Single Pair Ethernet）实现轻量化布线。支持 PoDL（Power over Data Line，数据线供电），满足汽车 EMC、延迟和可靠性要求。

📡 物理层标准

100BASE-T1 (100Mbps) 主流域内通信；1000BASE-T1 (1Gbps) 高带宽域控间通信和 ADAS；10BASE-T1S (10Mbps) 边缘节点传感器接入；2.5/5/10GBASE-T1 下一代高带宽场景。

🖼️ 帧结构

IEEE 802.3 以太网帧：前导码(7B) + SFD(1B) + 目的MAC(6B) + 源MAC(6B) + EtherType(2B) + 数据(46-1500B) + FCS(4B)。最小帧 64 字节，最大 1518 字节。

🏷️ VLAN (802.1Q)

4 字节 VLAN 标签插入在源 MAC 之后：TPID(0x8100) + PCP(3bit,QoS优先级) + DEI(1bit,可丢弃) + VID(12bit,最多 4094 个 VLAN)。实现流量隔离和优先级调度。

🌐 TCP/IP 协议栈

应用层(SOME/IP/DoIP) → 传输层(TCP/UDP, SoAd) → 网络层(IPv4/IPv6, TcpIp) → 数据链路层(Ethernet MAC, EthIf) → 物理层(100BASE-T1, EthTrcv)。AUTOSAR 中各层由对应 BSW 模块实现。

🔀 交换拓扑

车载以太网采用点对点连接+交换机转发，与 CAN 总线拓扑不同。ECU 通过以太网交换机互联，交换机根据 MAC 地址表转发帧，支持 VLAN 隔离不同域的流量。

⏱️ TSN 时间敏感网络

IEEE 802.1AS (gPTP 时钟同步，精度 <1μs) + IEEE 802.1Qbv (时间调度流量，通过 TAS 划分时隙)。三种流量：ST(硬实时)、RT(软实时)、BE(尽力而为)。

🔗 协议承载关系

以太网是物理传输基础，承载多种上层协议：SOME/IP（面向服务中间件）、DoIP（诊断）、XCP（标定）、gPTP（时间同步）、AVB（音视频桥接）。构成车内通信的骨干网络。
