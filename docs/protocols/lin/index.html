LIN 协议学习

局域互联网络 — Local Interconnect Network — 从主从调度到信号通信

LIN 协议基础概念

LIN（Local Interconnect Network）是一种低成本的单主多从串行通信协议，广泛应用于汽车车身电子系统中。

核心概念详解

👑 主从架构

LIN 采用单主多从架构，一个 Master 节点控制所有通信时序，最多 15 个 Slave 节点。Master 发送 Header，指定 Slave 响应。

📋 调度表 (Schedule Table)

Master 按预设的调度表轮询各 Slave 节点。调度表定义了帧的发送顺序和时隙，支持无条件帧、事件触发帧和偶发帧三种调度方式。

📨 帧类型

无条件帧（Unconditional）：固定周期收发；事件触发帧（Event-triggered）：数据变化时才响应；偶发帧（Sporadic）：仅当信号可用时发送；诊断帧（Diagnostic）：用于配置和诊断。

⚡ Break Field

帧起始标志，由至少 13 位显性电平（低电平）+ 1 位隐性电平（高电平）组成。Break 是 LIN 帧与普通 UART 数据的区别标志，用于唤醒总线和同步从节点。

🔑 Protected Identifier (PID)

6 位标识符 + 2 位奇偶校验位组成。ID 0-59 为信号帧，60-61 为诊断帧，62 为保留，63 为用户定义。校验位 P0 = ID0⊕ID1⊕ID2⊕ID4，P1 = ¬(ID1⊕ID3⊕ID4⊕ID5)。

🛡️ Checksum

两种校验类型：Classic（仅校验数据字段，兼容 LIN 1.x）和 Enhanced（校验 PID + 数据字段，LIN 2.x 推荐）。使用反向校验和（模 256 取反）。

🗺️ 信号映射

LIN 使用信号定义来描述数据字段中每一位的含义。通过 LDF（LIN Description File）配置信号的起始位、长度和编码类型（逻辑值、物理值、BCD 等）。

🔄 与 CAN 对比

LIN 是 CAN 的低成本替代方案：单线（1 线 vs CAN 双线）、低速（19.2 kbps vs CAN 1 Mbps）、主从（vs CAN 多主）、无仲裁机制、无错误检测（仅校验和）。LIN 适用于车门、座椅、空调等低成本场景。

📄 LDF 配置文件

LIN Description File 定义了整个 LIN 网络的配置：节点属性、信号定义、帧定义、调度表。相当于 LIN 的"数据库"，工具链根据 LDF 自动生成代码。

🏗️ 协议栈结构

5 层：应用层（信号/诊断）→ LIN 传输层（帧调度）→ LIN 协议层（帧结构）→ UART（串行通信）→ 物理层（单线总线）。

协议栈结构

LIN 协议遵循简化的五层模型，基于标准 UART 硬件实现，各层协同确保主从节点间的可靠通信。
