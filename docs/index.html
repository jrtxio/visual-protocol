推荐学习路径

自底向上 — 先理解基础传输层，再掌握上层应用协议

Step 1 已上线

LIN

局域互联网络

最简单的车载总线协议。单线主从架构，学习调度表、PID 和校验，为理解复杂总线打下基础。

ISO 9141 数据链路层
Step 2 已上线

CAN

控制器局域网络

车载网络的基石。理解 CAN 总线帧结构、仲裁机制和错误处理，为学习所有上层协议打下基础。

ISO 11898 数据链路层
Step 3 已上线

Ethernet

车载以太网

现代车载通信的骨干网络。掌握以太网帧格式、VLAN 和 TSN，理解 DoIP 和 SOME/IP 的承载层。

IEEE 802.3 物理 / 网络层
Step 4 已上线

TCP

传输控制协议

可靠传输的基石。掌握三次握手、滑动窗口和拥塞控制，理解 DoIP 等协议为何选择 TCP 传输。

RFC 9293 传输层
Step 5 已上线

UDP

用户数据报协议

低延迟传输的选择。无连接数据报模型，理解为何 DDS 和 SOME/IP 选择 UDP 作为底层传输。

RFC 8085 传输层
Step 6 已上线

DoIP

基于 IP 的诊断

基于 Ethernet 的诊断传输协议。学完 TCP 后自然衔接，理解诊断数据如何通过 IP 网络传输。

ISO 13400 传输 / 会话层
Step 7 已上线

UDS

统一诊断服务

诊断服务的核心协议。运行于 DoIP 或 CAN 之上，涵盖诊断会话、数据读取、例程控制等完整服务。

ISO 14229 应用层
Step 8 已上线

SOME/IP

面向服务的中间件

AUTOSAR 生态核心。基于以太网的面向服务架构，掌握服务发现、序列化和 RPC 通信机制。

AUTOSAR 中间件层
Step 9 已上线

MQTT

消息队列遥测传输

轻量级发布/订阅协议。掌握 Topic、QoS 和 Broker 机制，为理解 DDS 的高级中间件概念做铺垫。

OASIS 应用层
Step 10 已上线

DDS

数据分发服务

面向自动驾驶和 ADAS 的发布/订阅中间件。与 SOME/IP 互补，是 ROS 2 的底层通信机制。

OMG DDS 中间件层
